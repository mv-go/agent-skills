# Budget-Aware Swarm для Claude Code

Это самостоятельный плагин Claude Code с главным агентом Opus, исполнителями
Opus/Sonnet/Haiku и явным запуском схемы. Sonnet выполняет основную разработку,
Haiku — подходящие ограниченные задачи и массовую генерацию, Opus отвечает за
архитектуру, сложные решения и итоговую проверку. Схема сохраняет матрицу
делегирования исходного Codex skill, но использует средства Claude Code.

Для обычной установки используйте [релизные архивы](releases.md#claude-code).
Бандл `all-skills-<version>-claude.zip` уже содержит локальный marketplace
`tired-tools-releases` и пока один плагин Budget Aware Swarm. Агент скачивает
архив, проверяет его и распаковывает в постоянную папку средствами окружения.
Затем регистрирует эту папку через `claude plugin marketplace add <path>` и
ставит плагин `budget-aware-swarm@tired-tools-releases --scope user`.
Обновление архива завершается штатными командами обновления marketplace и
плагина: Claude хранит собственный кеш. Отдельного установщика нет.

Ниже сохранён путь установки **из исходного репозитория** для разработки и
существующих установок. При переходе на релизный marketplace сначала проверьте
его, затем отключите старую установку, чтобы не запускать две версии плагина.

Нужны Git и авторизованный Claude Code. Репозиторий `mv-go/agent-skills`
публичный, отдельный доступ к GitHub не нужен.

Пакет структурно проверен официальным CLI 2.1.321. Для работы
рекомендуется эта версия или новее; фактические модели и поля инструмента
проверяются в сессии. Это пакет для **Claude Code**, не для обычного чата claude.ai.

## Установка и запуск в рабочем проекте

Команды ниже — для macOS, Linux и WSL. В терминале:

```sh
claude --version
GIT_TERMINAL_PROMPT=0 GIT_ASKPASS=false git -c credential.interactive=false ls-remote https://github.com/mv-go/agent-skills.git HEAD
claude plugin marketplace add mv-go/agent-skills
claude plugin install budget-aware-swarm@tired-tools --scope user
CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS=49 claude --model opus --effort high
```

Последнюю команду выполните из папки своего рабочего проекта. Она задаёт
вместимость 49 подагентов плюс главный агент — всего до 50. Скилл сам выбирает
полезное число исполнителей по задаче. Если вы выбрали меньшую вместимость,
используйте её. Переменная действует на этот процесс и не меняет постоянные
настройки; настройки Claude Code могут переопределять её значение.
См. [официальное описание вместимости](https://code.claude.com/docs/en/sub-agents#concurrent-subagent-limit).

Если HTTPS не настроен, а GitHub доступен через SSH, вместо команды добавления
выше можно использовать:

```sh
GIT_SSH_COMMAND='ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ForwardAgent=no' git ls-remote git@github.com:mv-go/agent-skills.git HEAD
claude plugin marketplace add git@github.com:mv-go/agent-skills.git
```

Для SSH ключ уже должен быть доступен без запроса passphrase, а ключ хоста
GitHub — проверен и сохранён в `known_hosts`. Ошибку такой проверки нужно
устранить в своём обычном Git-доступе, сохраняя проверку ключа хоста.

В открывшейся сессии проверьте `/plugin`, `/agents`, `/status` и выбранный
effort через `/effort`. Должны появиться skill
`/budget-aware-swarm:budget-aware-swarm` и три агента `swarm-opus`,
`swarm-sonnet`, `swarm-haiku` с префиксом `budget-aware-swarm:`.
Если политики организации блокируют частные плагины или нужные модели,
это необходимо решить в конфигурации своей организации.

Для запуска:

```text
/budget-aware-swarm:budget-aware-swarm Выполни рабочую задачу в этом проекте: [описание задачи]. Критерии готовности: [ожидаемый результат]. Сам выбери число исполнителей по схеме, соблюдая матрицу моделей, потолок 50 вместе с главным агентом и фактические лимиты среды. Внеси изменения, проведи необходимые проверки и покажи результат, проверки и распределение работы между агентами.
```

Skill работает в основном разговоре и действует до завершения этой задачи.
Сам он не переключает главную модель и не назначает ей effort. Модель и effort
определяются по отдельности. Если сессия видит значение сама, оно считается
верным; если вы указали другое, скилл скажет об этом одной строкой и продолжит
со значением сессии. Если сессия значение не видит, принимается ваше указание
(`user-declared`, фактическое значение `unverified`). Если значения нет ни у
сессии, ни у вас, скилл один раз спросит его и поставит задачу на паузу.

Если задана `CLAUDE_CODE_EFFORT_LEVEL`, она может переопределять effort всех
исполнителей. Принудительная настройка модели подагентов тоже может нарушить
маршрутизацию. В этом случае схема сообщает о конфликте; не считает запрошенные
параметры доказательством фактических. Подробности и источники — в
[runtime reference](../plugins/budget-aware-swarm/skills/budget-aware-swarm/references/runtime.md).

## Облачные сессии (claude.ai/code и телефон)

Облачная сессия не ставит плагины, даже если репозиторий включает их в
`.claude/settings.json`. Зато она загружает скиллы из `.claude/skills/`
склонированного репозитория и скиллы, включённые на claude.ai.

- **В этом репозитории** скилл лежит в `.claude/skills/budget-aware-swarm/` и
  подхватывается сам. Вызов: `/budget-aware-swarm <задача>` или упоминание
  схемы Budget-Aware Swarm по имени в тексте задачи; сам по себе Claude скилл
  не выбирает. Это копия скилла
  из плагина; тест `tests/test_claude_plugin.py` следит, чтобы они совпадали.
- **В других репозиториях** загрузите папку скилла на claude.ai как свой скилл
  (архив `budget-aware-swarm` с `SKILL.md` и `references/`), либо скопируйте её
  в `.claude/skills/` нужного репозитория.

Профилей `swarm-*` из плагина в облаке нет, поэтому скилл запускает
`general-purpose` с явной моделью (`haiku`, `sonnet`, `opus`) и effort.
В облаке `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1`: сабагенты не могут
запускать своих сабагентов. Скилл переходит в плоский режим: раздаёт работу
только главный агент, по умолчанию Haiku; Sonnet получает лишь то, что нельзя
разбить на задачи для Haiku или что Haiku не сделал за две попытки; Opus —
только после неудачи Sonnet. Модель и effort главного агента скилл берёт из
`get_session` и `CLAUDE_EFFORT`; если вы указали другое, он сообщит о
расхождении и будет исходить из данных сессии.

Задание Haiku рассчитано так, чтобы весь его прогон уложился примерно в 100
тыс. токенов контекста. Каждый шаг агента — отдельный запрос со всей историей,
и шаг, чей запрос длиннее 100 тыс. токенов, целиком тарифицируется в пять раз
дороже. Размер задания оценивается в токенах, а не в числе файлов: примерно
`wc -c` входных данных, делённое на четыре. На чтение отводится около половины
бюджета, остальное — на служебный контекст агента, вывод команд и ответы.
Итоговые токены завершённых воркеров служат калибровкой для следующих заданий.

## Запуск из клона без установки

В отдельной папке клонируйте репозиторий:

```sh
git clone --branch main https://github.com/mv-go/agent-skills.git agent-skills-claude
cd agent-skills-claude
claude plugin validate ./plugins/budget-aware-swarm
claude plugin validate .
```

Затем из папки своего рабочего проекта запустите Claude, подставив
абсолютный путь к клону:

```sh
CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS=49 claude --model opus --effort high --plugin-dir /absolute/path/agent-skills-claude/plugins/budget-aware-swarm
```

`--plugin-dir` загружает плагин только на эту сессию. Не передавайте ему корень
репозитория: нужный manifest находится внутри `plugins/budget-aware-swarm`.
Так можно работать с пакетом без постоянной установки.
См. [официальный запуск локального плагина](https://code.claude.com/docs/en/plugins/create#develop-without-a-marketplace).

## Проверка результата рабочей задачи

Сразу дайте свою рабочую задачу с ожидаемым результатом. Схема распределяет
её независимые части между подходящими исполнителями, вносит изменения и
проверяет результат. Число агентов определяется задачей и доступной вместимостью.
Тривиальную последовательную правку главный агент может выполнить сам.

В итоговом отчёте должны быть результат, изменённые файлы, выполненные проверки
и распределение работы между агентами. `requested`, `effective`, `unverified`
и доступная телеметрия указываются раздельно. Во время работы `/tasks` и
сообщения Claude Code помогают увидеть подмены моделей. Runtime может заменить
модель до того, как главный агент узнает об этом: при доступном свидетельстве
конфликта агент останавливает соответствующую работу, без телеметрии отмечает
неопределённость. Prompt не гарантирует обнаружения или предотвращения подмены.

Проверка manifest подтверждает структуру пакета. Поведение и полезность схемы
оцениваются по результату этой рабочей задачи; фиксированная экономия и точный
остаток подписочного лимита не обещаются.

## Лимиты и обновления

50 агентов вместе с главным — потолок политики, не обещание вместимости
Claude Code. Реальный лимит сессии, глубина и меньший пользовательский бюджет
имеют приоритет. Команда запуска выше запрашивает 49 подагентов; без настройки
документированный лимит Claude Code равен 20. Скилл проверяет доступные
настройки и метаданные сессии. Если вместимость не удаётся подтвердить, он
отмечает её как `unknown` и выбирает полезный параллелизм в рамках матрицы и
потолка 50. При отказе runtime из-за вместимости ждёт освобождения слотов и
пересчитывает распределение. Отдельного ограничения одним или двумя агентами
нет. Число 50 обозначает максимум, а не требуемое число исполнителей.

`maxTurns` в профилях ограничивает отдельный запуск, а не токены и не стоимость.
Матрица моделей, права записи в файлы, попытки и временные рамки — инструкции.
Плагин не меняет настройки host, sandbox, MCP или SSH и не требует WikiLayer.
Для интеграций действуют отдельные указания проекта.

Обновление и удаление из терминала:

```sh
claude plugin marketplace update tired-tools
claude plugin update budget-aware-swarm@tired-tools
claude plugin uninstall budget-aware-swarm@tired-tools
```

После обновления начните новую сессию и перепроверьте компоненты.
Авторы должны повышать `version` в plugin manifest при выпуске изменений:
одного обновления файлов marketplace недостаточно для уже установленной версии.
См. [marketplace и обновления](https://code.claude.com/docs/en/plugins/host-marketplace).

Плагин целиком находится в `plugins/budget-aware-swarm/`; он не зависит от
файлов Codex skill вне этого каталога. Существующий `scripts/install.py`
по-прежнему устанавливает только Codex-вариант и для Claude не нужен.
